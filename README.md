# Estech Solutions Website

Estech Solutions is positioned as an AI Operations Partner for logistics, haulage, freight forwarding, customs brokerage, warehousing, and supply chain companies.

## Mission
Reduce repetitive operational work so logistics companies can lower operating costs, respond faster to customers, reduce mistakes, and improve visibility.

## Vision
A logistics industry where routine coordination is automated, exceptions are visible, and operations teams spend more time solving customer and revenue problems.

## Architecture
This is a static website built with semantic HTML, Bootstrap, shared CSS, and lightweight JavaScript. Pages are optimized for search discovery, fast delivery, and maintainable content expansion.

## Technology
- HTML5
- Bootstrap 5
- Shared design system in `assets/premium.css`
- Reveal and navigation interactions in `assets/premium.js`
- ROI calculator logic in `assets/roi-calculator.js`
- XML sitemap and robots directives
- Schema.org structured data on key pages

## Deployment
Deploy the repository as a static site on Vercel, Netlify, GitHub Pages, or any static hosting provider. The production domain used in metadata is `https://estechsolutions.vercel.app/`.

## Project Structure
- `index.html` — homepage and core positioning
- `ai-for-*.html` — dedicated industry landing pages
- `resources.html` and `resources/*.html` — SEO resource library
- `roi-calculator.html` — interactive productivity estimator
- `works.html` — case-study examples
- `contact.html` — operations review form
- `assets/` — CSS and JavaScript assets
- `sitemap.xml` and `robots.txt` — technical SEO files

## Contribution Guide
Keep copy outcome-led and executive-friendly. Do not lead with generic AI language. Every page should answer: what operational cost is reduced, what process gets faster, why the buyer should trust Estech, and what happens next.

## Company Positioning
Estech is not positioned as a software agency. Estech is an AI Operations Company helping logistics and supply chain businesses improve operational performance.
